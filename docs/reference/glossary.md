# Glossario

> **Stato:** implementato  
> **Fonte di verità:** vocabolario usato nel codice e nella documentazione

| Termine | Definizione |
|---|---|
| ABI | Contratto pubblico condiviso da host e provider |
| ADR | Documento immutabile nel significato che registra una decisione accettata |
| Bundle | Gruppo montabile di provider, risorse e lifecycle |
| Capability | Famiglia di operazioni che una policy può concedere o negare |
| Documento canonico | Pagina che descrive il comportamento corrente e verificato |
| Host | Componente che monta sessioni, bundle e porte concrete |
| Kernel | Core che possiede stato e policy del vault |
| Plugin | Unità estendibile con identità, manifest, provider e lifecycle |
| Provider | Implementazione di un punto di estensione |
| RFC | Proposta tecnica aperta, non ancora parte del comportamento corrente |
| Shell | Interfaccia TypeScript che disegna e gestisce interazioni locali |
| Sidecar | File di servizio associato a un altro elemento |
| Superficie | Contesto interattivo in cui la shell monta un contenuto o una view |
| Vault | Radice locale dei documenti e dello stato associato |
| WIT | Linguaggio del contratto dei componenti WebAssembly |

Un termine viene definito qui solo quando serve in più aree. Le definizioni specifiche restano accanto al loro uso.
