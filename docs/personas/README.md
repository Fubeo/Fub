# Personas

Le personas descrivono utenti e contesti di lavoro usati per valutare le scelte di prodotto. Non sono requisiti tecnici, statistiche sugli utenti reali o funzioni già implementate.

Usale per rispondere a domande come:

- chi incontra questo problema;
- quale informazione deve vedere per decidere;
- quale perdita o interruzione sarebbe inaccettabile;
- quale livello di complessità è ragionevole esporre.

Una decisione architetturale non deve essere giustificata soltanto da una persona ipotetica: va collegata a un requisito in [`features/`](../features/README.md), a una microfunzionalità osservabile o a un verbale in [`decisions/`](../decisions/README.md).
