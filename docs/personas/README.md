# personas/

Materiale di ricerca: sei personas e le sei interviste esplorative da cui
vengono. Sta qui perché è la **fonte** di una parte di
[FEATURES.md](../FEATURES.md) e di tutta
[appendix/funzionalita-future.md](../appendix/funzionalita-future.md) — quando
una funzionalità futura si giustifica con «serve a chi studia», questo è il
posto dove è scritto chi studia e cosa gli serve.

**È materiale datato e congelato.** Le interviste sono del 24/07/2026 e non si
aggiornano: una ricerca riscritta a posteriori non è più una ricerca. Se i
bisogni cambiano, si intervista di nuovo e si aggiunge un file.
