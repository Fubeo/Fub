# Fub — Catalogo delle feature

**Versione:** 1.1 consolidata (+ microfeature collegate)
**Scope:** unire in un unico catalogo ordinato tutte le feature fondamentali di **Fub** e della futura **FubSuite**, includendo sia la lista iniziale sia le feature aggiuntive emerse dopo.

Il catalogo completo è suddiviso in **un file per sezione** nella cartella `docs/features/`; questo documento è l'indice che vi collega. Le feature banali di uso quotidiano (gesti atomici: tasti, click, drag, focus, zoom, menu contestuali) vivono nei file di [microfeature](microfeatures/), collegati alle sezioni corrispondenti (§32).

---

## Legenda

- **Core** = funzionalità base dell'app
- **Suite** = plugin nativo ufficiale FubSuite
- **Plugin** = funzionalità estendibile via plugin
- **Opzionale** = attivabile/disattivabile dall'utente
- **Privacy** = funzionalità con impatto su privacy/sicurezza
- **Anti-predatorio** = vincolo di prodotto non negoziabile
