# Microfeature — Editor di testo

**Collegata a:** [Master Feature Document](../FEATURES.md) — sezioni 3.3 e 4
**Scopo:** feature essenziali e banali, di uso quotidiano, non ancora elencate nel master document.

## Movimento del cursore

- [ ] Frecce direzionali (←↑↓→) per spostare il cursore
- [ ] Home/End per inizio/fine riga

- [ ] Page Up/Page Down
- [ ] Ctrl+freccia sinistra/destra per salto di parola
- [ ] Ctrl+freccia su/giù per salto di paragrafo
- [ ] Click del mouse per posizionare il cursore

- [ ] Trascinamento del mouse per selezionare

- [ ] Triplo click seleziona la riga/paragrafo
- [ ] Shift+click estende la selezione

- [ ] Ctrl+Shift+frecce estende la selezione per parola
- [ ] Shift+Home/End estende a inizio/fine riga
- [ ] Ctrl+A seleziona tutto
- [ ] Esc deseleziona
- [ ] Autoscroll trascinando oltre il bordo
