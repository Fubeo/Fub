# Microfeature — Markdown e preview

**Collegata a:** [Master Feature Document](../FEATURES.md) — sezioni 5 (Markdown: standard, estensioni e sicurezza) e 6 (Rendering, preview, temi e stampa)
**Scopo:** feature essenziali e banali, di uso quotidiano, non ancora elencate nel master document.

## Inserimento guidato

- [ ] Toolbar con pulsanti per formattazione base (grassetto, corsivo, heading, liste, link, immagine, citazione, codice, tabella, riga orizzontale)
- [ ] Dialog inserimento link (URL + testo visibile)
- [ ] Dialog inserimento immagine (percorso/URL + alt text)
- [ ] Inserimento guidato tabella (numero righe e colonne)
- [ ] Inserimento guidato code block con scelta della lingua
- [ ] Inserimento blockquote
- [ ] Inserimento riga orizzontale (---)
- [ ] Barra di formattazione fluttuante sulla selezione di testo

## Tabella

- [ ] Tab per spostarsi tra le celle
- [ ] Invio in cella va alla riga sottostante
- [ ] Tab nell'ultima cella crea una nuova riga

## Interazione con la preview

- [ ] Click su link nella preview apre la nota o l'URL
- [ ] Ctrl+click su link nella preview apre in nuova scheda
- [ ] Click su link esterno nella preview apre nel browser
- [ ] Click sul checkbox di una task la toggla
- [ ] Selezione e copia del testo renderizzato
- [ ] Trova nella preview (Ctrl+F)
- [ ] Zoom della preview (Ctrl+rotellina)
- [ ] Home per tornare in cima alla preview
- [ ] Incollare un URL su testo selezionato lo trasforma in link
