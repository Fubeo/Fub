**Scopo:** feature essenziali e banali, di uso quotidiano, non ancora elencate nel master document.

- [ ] Minimizza finestra
- [ ] Massimizza/ripristina finestra
- [ ] Chiudi finestra
- [ ] Ridimensiona finestra trascinando i bordi
- [ ] Titolo finestra con il nome della nota aperta
- [ ] Indicatore di modifiche non salvate nel titolo della finestra
- [ ] Conferma uscita con modifiche non salvate

## Menu di sistema

- [ ] Menu File standard (nuovo, apri, salva, chiudi, esci)
- [ ] Menu Modifica standard (annulla, copia, incolla, trova)
- [ ] Menu Visualizza standard
- [ ] Menu Aiuto
- [ ] F1 apre la documentazione
- [ ] Scorciatoie di sistema visibili nei menu

## Dialoghi e focus

- [ ] Esc chiude i dialoghi
- [ ] Invio conferma il dialogo (pulsante predefinito)
- [ ] Tab naviga tra i campi del dialogo
- [ ] Shift+Tab torna al campo precedente
- [ ] Il focus torna all'editor dopo le operazioni

## Impostazioni e avvio

- [ ] Ctrl+, apre le impostazioni
- [ ] Avviso prima di chiudere un dialogo con modifiche non salvate
