# Microfeature — Media e allegati

**Collegata a:** [Master Feature Document](../FEATURES.md) — sezioni 13 (Allegati, media, annotazioni e audio/video)
**Scopo:** feature essenziali e banali, di uso quotidiano, non ancora elencate nel master document.

## Viewer immagini

- [ ] Click su un'immagine apre il viewer
- [ ] Frecce navigano tra le immagini del viewer
- [ ] Esc chiude il viewer
- [ ] Click fuori dall'immagine chiude il viewer
- [ ] Rotellina del mouse zooma nel viewer
- [ ] Doppio click riporta lo zoom al 100%
- [ ] Drag per pan quando si è in zoom
- [ ] Nome del file mostrato nel viewer
- [ ] Copia l'immagine negli appunti dal viewer

## Audio e video

- [ ] Barra spaziatrice fa play/pausa
- [ ] Frecce saltano avanti/indietro nel player
- [ ] Click sulla timeline salta alla posizione
- [ ] Pulsante fullscreen nel player
- [ ] Pulsante mute nel player
- [ ] Rotellina sul player regola il volume
- [ ] Regolazione della velocità di riproduzione (0.5x–2x)

## PDF

- [ ] Rotellina del mouse scorre il PDF
- [ ] Ctrl+rotellina zooma nel PDF
- [ ] Frecce cambiano pagina nel PDF
- [ ] Indicatore di pagina nel viewer
- [ ] Pulsante adatta alla larghezza
- [ ] Ricerca nel PDF con Ctrl+F e evidenziazione delle occorrenze
- [ ] Drag per pan quando si è in zoom

## Allegati

- [ ] Click su un allegato lo apre con l'applicazione di sistema
- [ ] Apri la cartella contenente l'allegato
- [ ] Tooltip con dimensione e tipo dell'allegato
