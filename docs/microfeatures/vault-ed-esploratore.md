# Microfeature — Vault ed esploratore

**Collegata a:** [Master Feature Document](../features/01-principi-fondanti.md) — sezioni 3.1-3.2 (Vault e file explorer), 7 (Link, backlink, transclusione e grafo) e 8 (Organizzazione, metadata, tassonomia e collezioni)
**Scopo:** feature essenziali e banali, di uso quotidiano, non ancora elencate nel master document.

## Esploratore file

- [ ] Doppio click su una nota la apre
- [ ] Invio apre la nota selezionata nell'albero
- [ ] F2 rinomina il file in-place
- [ ] Canc cestina il file selezionato
- [ ] Scorciatoia per nuova nota
- [ ] Scorciatoia per nuova cartella
- [ ] Freccia accanto a una cartella la espande o collassa
- [ ] Doppio click su una cartella la espande o collassa
- [ ] Espandi/collassa tutte le cartelle
- [ ] La nota attiva è evidenziata nell'albero (reveal)
- [ ] Scroll automatico dell'albero alla nota attiva
- [ ] Ordinamento alfabetico di default
- [ ] Icone per tipo di file nell'albero
- [ ] Mostra l'estensione dei file
- [ ] Apri la cartella nel file manager di sistema
- [ ] Apri il file con l'applicazione di sistema
- [ ] Tooltip con percorso completo del file
- [ ] Click su una cartella la seleziona senza espanderla
- [ ] Menu contestuale nell'albero con nuova nota, nuova cartella, rinomina, duplica e cestina
- [ ] La nuova nota viene creata nella cartella selezionata

## Vault

- [ ] Menu a tendina per cambiare vault
- [ ] Nome del vault visibile nella finestra

## Link

- [ ] Click su un wikilink apre la nota
- [ ] Ctrl+click su un wikilink apre in nuova scheda
- [ ] Alt+click su un wikilink apre in split
- [ ] Click su un link esterno apre nel browser di sistema
- [ ] Copia link
- [ ] Copia come link Markdown
- [ ] Menu contestuale sui link con apri, apri in nuova scheda e copia

## Organizzazione rapida

- [ ] Ctrl+P apre il quick switcher
- [ ] Digitare nel quick switcher filtra i risultati
- [ ] Frecce nel quick switcher navigano i risultati
- [ ] Invio nel quick switcher apre il risultato selezionato
- [ ] Ctrl+Shift+P apre la command palette
- [ ] Click su un tag apre la ricerca di quel tag
- [ ] Click su un heading nell'outline naviga alla sezione
- [ ] Nota attiva evidenziata nell'outline
- [ ] Data relativa nelle note recenti
- [ ] Stella per aggiungere una nota ai preferiti
- [ ] Riordina i preferiti con drag & drop
