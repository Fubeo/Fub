# frontend/

La webview dell'app usa Vite, TypeScript e CodeMirror 6.

La documentazione canonica vive in:

- [`docs/architecture/ui-shell.md`](../docs/architecture/ui-shell.md) — moduli, stato e responsabilità della shell;
- [`docs/reference/ui-protocol.md`](../docs/reference/ui-protocol.md) — protocollo dichiarativo fra provider e frontend;
- [`docs/guides/testing.md`](../docs/guides/testing.md) — test, banco visuale e accessibilità.

Questo README è soltanto una porta locale e non duplica l'architettura.

## Comandi

```bash
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

L'avvio completo dell'app è nel [README della radice](../README.md).
